Proyectos y Sistemas Construidos

Plataforma Self-Hosted — Homelab en Proxmox

Homelab estilo producción sobre Proxmox VE + LXC, operado como una plataforma real: infraestructura como código, monitoreo autónomo y estrategia de respaldo 3-2-1.

  • IaC: aprovisionado y versionado con Terraform; definiciones reproducibles de contenedores y servicios.
  • Operación auto-reparable: workflows en n8n consultan la API de Proxmox a diario, detectan contenedores caídos o backups fallidos y alertan por Telegram. Silencio = todo OK.
  • Resiliencia: pipeline de respaldo 3-2-1 (offsite + local + escritorio) con verificación automatizada; DNS interno con filtrado (AdGuard) y mesh VPN (Tailscale) para acceso remoto seguro.
  • Mantenimiento sin manos: systemd timers en CachyOS Linux parchean toda la flota cada semana y registran el resultado en Notion vía webhook.
Repo: github.com/gustavodiaz-dev/homelab
